# MTGCraft downloads

Ready-to-use mod jars. Click a jar below, then the **Download** button (or "View raw").

| File | For | Minecraft |
|------|-----|-----------|
| `mtgcraft-0.3.0.jar` | All the Mods 9 (ATM9) | 1.20.1, Forge 47.4+ |

## Install
1. Delete the old `mtgcraft-*.jar` from your instance's `mods` folder.
2. Put the new jar in the `mods` folder (on the server too, if you play on one).
3. Servers need about 4 GB of memory or more for the card engine.

Your own duel sound: put `duel_start.ogg` in the instance's `mtgcraft` folder; it isn't part of the jar.
